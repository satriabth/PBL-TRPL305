CARA TEST - APLIKASI MICROCREDENTIAL (MODE DEMO)
================================================

CARA PALING MUDAH (Windows):
  1. Ekstrak seluruh isi zip ini ke satu folder
  2. Dobel-klik file  JALANKAN_DEMO.bat
  3. Browser Chrome akan terbuka otomatis menampilkan aplikasi
  4. Untuk menghentikan: tutup jendela hitam (Command Prompt)

  * Butuh Python untuk menjalankan (lihat keterangan di dalam .bat
    bila muncul pesan error Python tidak ditemukan).
